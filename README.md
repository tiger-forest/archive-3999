# 档案：编号3999

基于 SCP 基金会经典条目《SCP-3999：我于万物之中》（*SCP-3999 - I Am At The Center of Everything That Happens To Me*）改编的单文件伪终端交互叙事作品。

你扮演 3 级研究员 **詹姆斯·塔罗兰（James Talloran）**，在 `SCiPNET-EDIT v4.0` 归档终端中起草并维护 SCP-3999 的档案，同时与侵入文档的现实扭曲异常展开文字对抗。

---

## 游玩方式

### 方式一：浏览器直接游玩（推荐）
* 若已开启 GitHub Pages，可直接访问在线页面体验；
* 或直接下载仓库中的 [index.html](index.html) / [scp_3999_scipnet_edit_v4_0.html](scp_3999_scipnet_edit_v4_0.html)，使用任意现代浏览器（Chrome / Edge / Firefox）打开即可。
* **纯单文件、零外部依赖**：无需联网加载字体或音频，所有音效均通过内置 Web Audio API 实时合成。

### 方式二：Windows 独立启动程序
* 可在 `dist_exe/` 目录或 Releases 页面获取 [SCP-3999.exe](dist_exe/SCP-3999.exe)。
* 双击后将以无边框独立全屏应用窗口启动（内置 Edge/Chrome `--app` 壳，本地进度自动持久化保存，按 `F11` 或将鼠标移至屏幕顶部可切换/退出）。

---

## 基本操作
* **`[1] 【数据删除】`**：遮盖涉密信息或压制异常词条。
* **`[2] 删除线 ~~`**：划除作废附注或阻断异常写入。
* **`[3] 剪贴板`**：点击顶部参考词条复制并填入文档空缺处。
* **底部参考栏**：点击候选公文或应对条款写入文档。
